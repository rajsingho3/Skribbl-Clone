# 🎨 Skribbl-Clone

A real-time multiplayer drawing and guessing game inspired by Skribbl.io, built using modern full-stack technologies.

🔗 **Live Demo:**  
👉 https://skribbl-clone-indol.vercel.app/

---

## 🚀 Tech Stack

### 🖥 Frontend
- React (Vite)
- TypeScript
- Tailwind CSS
- Socket.IO Client

### ⚙ Backend
- Node.js
- Express
- TypeScript
- Socket.IO

---

## 📁 Project Structure

Skribbl-Clone/
│
├── backend/     # Node + TypeScript + Socket.IO server  
└── frontend/    # React + Vite + Tailwind client  



## Backend Setup
